What this is. ruvltra-claude-code-0.5b-q4_k_m.gguf is byte-for-byte Qwen2-0.5B-Instruct (verified by SHA256 — see experiment 02). It runs here through llama.cpp compiled to WebAssembly, on your CPU. First load downloads ~398 MB; after that it is served from browser cache and works offline.

Expect it to be slow and a bit daft. That is the game. A 0.5B model in single-threaded WASM generates a few tokens per second, and it is exactly gullible enough to be fun to trick.
