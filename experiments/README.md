# Experiments

One directory per experiment, named `NN-short-slug` (e.g. `01-claude-flow-hello-swarm`).

Each experiment directory carries its own `README.md` covering:

- **What question it answers** — one sentence.
- **How to run it** — exact commands, from a clean checkout.
- **Versions** — component versions or commit SHAs it was run against.
- **Result** — what happened, including when the answer was "this doesn't work".

Experiments are allowed to be throwaway. They are not allowed to be undocumented.
