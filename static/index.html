What is Meshtastic?

Meshtastic is an open-source, off-grid mesh networking project built on cheap, low-power LoRa radios. Devices talk directly to each other over long-range radio (kilometers, not meters) with no cell towers, no carrier, and no internet required — and every device can relay other devices' messages onward, so a message can hop across many nodes to reach far beyond any single radio's range. It's used for hiking/off-grid comms, emergency networks, and general LoRa tinkering.

How does mesh traffic get onto the internet?

Meshtastic nodes with an internet-connected gateway can bridge their local mesh traffic onto a shared public MQTT broker (mqtt.meshtastic.org), using a documented topic layout: msh/<REGION>/2/json/<CHANNEL>/<NODE_ID>. MQTT is a lightweight publish/subscribe protocol: publishers send small JSON packets to a topic, and anyone subscribed to that topic (or a wildcard match) receives them in real time.

What this app does

This dashboard subscribes to that public broker's LongFast channel (the default human-chat channel) across all regions, parses each packet — text messages, GPS positions, battery/telemetry, and node identity — and keeps a live, in-memory registry of nodes and messages, rendered here and refreshed every few seconds. No hardware, pairing, or radio required: it's purely observing real traffic that other people's gateways are relaying onto the internet.

It also publishes: the "Send a message" box below publishes your text back onto the same broker under a virtual node called "Web Dashboard", which is how you see your own messages appear in the feed. That message is genuinely visible to anyone else watching the public broker too — but it is not guaranteed to reach real LoRa radios, since gateway operators keep "downlink" (internet → mesh) off by default to protect their own limited, regulated radio airtime from being flooded by internet traffic.

Why build this

It's a small, hands-on way to learn Meshtastic's actual data model and integration surface (MQTT topics, JSON packet schema, node/channel concepts) by building real, working tooling against the live public network — the same approach a mapping tool, chat bot, or home-automation integration would take.
